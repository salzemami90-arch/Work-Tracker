# Work Tracker — Final Hands-On Review

Open **http://127.0.0.1:8771/#overview** in the same browser. This is the candidate workspace; each browser and address keeps separate records. No example records are preloaded.

If the local server needs restarting, run this in Terminal:

```sh
bash ./run-browser.sh 8771
```

Keep that Terminal window open. No installation or permission change is needed.

1. **Create a practice project.** Choose an icon. Add two goals and two steps under the first goal. Edit a title or description and try the Move up/Move down controls.
2. **Record progress and adapt the plan.** Complete one step, add a note after completion, then reopen it from its step options. Move a step to the second goal. Check that the original achievement and note remain in Progress History. Removing a step should put it in Removed steps, where it can be restored.
3. **Record context.** Add a summary, an issue, and a personal note using Notes & updates or the project panels. A helper name is optional. Edit an entry and inspect its before/after history. Set Next action to the small action to start with next time.
4. **Check planning.** Plan an unfinished step for yesterday and give it a separate deadline. Find it in Today/This Week. Defer it, reschedule it, then pause and resume the project. Its deadlines and history should remain visible.
5. **Try cancellation and returning.** Change a form, choose Cancel, then Continue editing; the draft should remain. Cancel again and Discard changes; saved text should remain. Refresh the page and check the project, notes, next action, and achievements.
6. **Export and review.** Use Backup & restore to download a backup and inspect its preview. Restoring replaces the current workspace, so try replacement only with fictional records or the separate practice site on port 8772. An automatic recovery copy should appear after restore.

Switch between English and Arabic and resize the window. Navigation stays at the side above 700px and moves to the top at 700px or below.

Report any confusing control or unexpected result with the page name and what happened. Final acceptance and publication remain separate; this trial does not publish anything.
